# Build the coding-only low-memory OpenCode variant contract and fork PR plan

## Hypothesis / objective

A reviewable coding-only OpenCode variant can be fully specified from the
#77 inventory without a custom provider rewrite: a dedicated entrypoint +
`build:coding` target that physically excludes TUI/web/ACP/serve, share,
MCP, LSP/formatter, plugin-install, question/websearch, snapshot-worktree,
watcher-impl, update/catalog, and unused providers from the static import
graph, keeps the provider/agent/tool loop and the minimal tool set, gates
each removal group (A-D) on a benchmark rerun, and proves boundaries with
offline tests — with the fork PR materialized by the workflow (issue
execution performs no git pushes or PR creation).

## Interpretation

- Configuration alone (step-0 flags) can suppress runtime init but cannot
  shrink the Bun single binary; the saving must come from the new coding
  entrypoint plus lazy bootstrap/registry/routes plus dependency pruning,
  each gated on measurement — which is what the contract encodes.
- Snapshot (`track`/`patch` unconditional), sqlite `Database`/storage, the
  in-process `fetch` mechanism, provider auth/transform, watcher HEAD
  subscription, and compaction wiring cannot be cut; the variant keeps
  their interfaces and lazifies only backends — so correctness is
  preserved by construction and proven by the representative task.
- `task`/`todo`/`invalid` stay retained (tiny); `question`/`websearch`/
  `lsp`/`plan`/`code-mode` are the safe tool cuts; `skill`/`webfetch` stay
  conditional via dynamic import. No provider rewrite exists anywhere in
  the plan (validator fails closed on `direct-provider-client` et al).
- The fork PR cannot be opened from issue execution (workflow owns Git
  state) and the #78 delta cannot be measured before #78 lands; both are
  specified as procedures (PR branch/files/body; per-group reruns) rather
  than claimed as done.

- Coding-entry shape that actually shrinks the graph: a separate
  `coding-index.ts` importing only `RunCommand` (+ ui/error/heap), never

  static imports.
- Registry cut line: keep
  read/glob/grep/edit/write/apply_patch/shell/task/todo/invalid (+ lazy
  skill/webfetch); drop question/websearch/lsp/plan/code-mode —
  verified against live `registry.ts` imports.

  lsp/shareNext/format; no-op snapshot backend (processor calls
  `track`/`patch` unconditionally); lazy watcher impl — verified against
  live `bootstrap.ts` eager six-init.

  only top-level `import ... from` (dynamic `import()` exempt); full

  MB + fresh hermetic `--version`; define per-group Docker 512m/no-swap
  reruns instead of claiming bulk savings.
