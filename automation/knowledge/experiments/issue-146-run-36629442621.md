# Refuse foreign-repository PR #15 transports pre-creation (repair run 36511901291)

## Hypothesis / objective

Run 36511901291 (source issue #141, smoke) failed in `render-job.sh` at the
exact-artifact controller fetch with `urllib.error.HTTPError: HTTP Error 404:
Not Found` from `download_exact_artifact_zip`, after an ephemeral Render
service had already been created (execute=failure, cleanup=success). Objective:
identify the root cause from log evidence, fix the reusable gate/delivery
implementation so this failure class refuses pre-creation with zero Render
cost, regression-lock it, and keep the change scoped (no workflow edits, no
git mutations, no source-issue #141 changes).

## Interpretation

- The gate's shape-only PR #15 check let any numeric triple carrying the pinned
  binary digest ride the delivery path. The one-shot publish's runtime-lab
  triple passed it, and the repo-pinned fetch then 404d. The refusal-to-substitute
  behavior was correct, but it fired too late: after paying for a service
  create/deploy/health cycle instead of refusing pre-creation in seconds.
- Pinning the transport triple plus enforcing the `kodmial/opencode` repository
  declaration closes the class: the bad triple now refuses at
  `exact_artifact_gate_decision` with `infrastructure-blocked` + a note naming
  the pinned publish, so `render-job.sh` exits (line 293) before any Render API
  service call (line 300+). The published #141 triple is unaffected (still
  delivers with an empty blocker and full identity).
- The prior `6c0617d` repair reached the identical conclusion on a different
  base; agreement across two bases strengthens the diagnosis rather than
  conflicting with it, and this record preserves that history instead of
  rewriting it.

## Reusable knowledge

- GitHub Actions artifact IDs are scoped to their source repository
  (`GET /repos/{owner}/{repo}/actions/artifacts/{artifact_id}/zip`); delivery
  code that fetches from a hardcoded repo must pin the full transport triple
  and the repository declaration, never "any numeric transport".
- A correct fail-closed refusal can still be too late: gate placement decides
  cost. The #146 fix moves this class from post-creation fetch-404 to
  pre-creation refusal (zero Render cost).
- To route a future re-published PR #15 build, add its triple to
  `SUPPORTED_PR15_ARTIFACTS` in both `render_lifecycle.py` and
  `exact_artifact_delivery.py` explicitly.
