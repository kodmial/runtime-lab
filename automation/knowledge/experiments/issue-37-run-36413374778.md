## Preconditions / changed premise
Material premise changed versus run 36411929515: (1) the `TAP_PAT` repository secret was added/updated by the user, arriving in this workflow as `GH_TOKEN`/`GITHUB_TOKEN` (literal `TAP_PAT` env remains absent; both token envs length 40, values never read); (2) the correct endpoint was identified as `POST /user/repos` (`kodmial` is a personal `User` account, confirmed via `GET /user` returning `login=kodmial, type=User`); (3) `kodmial/agent-knowledge` did not exist (authenticated `GET /repos/kodmial/agent-knowledge` returned 404; anonymous `GET https://api.github.com/repos/kodmial/agent-knowledge` returned HTTP 404 with no disclosure). This run does not repeat the old experiment; it executes the corrected retry the issue requires.
