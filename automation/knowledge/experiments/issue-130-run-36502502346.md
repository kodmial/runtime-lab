## Reusable knowledge

- A coordinator that cannot touch workflow files can still be durable: persist the target, streak, locks, and seen-event ids in a repository JSON file and let the existing scheduler envelope wake reconciliation.
- Classify correctness failures with zero pressure as functional, never as OOM; classify version/SHA/identity mismatches as infrastructure, never as memory; only `oom_kill`/`137`/at-ceiling-nonzero-exit is memory.
- Marginal (pass + over-target or throttled) must route to optimization, never to integration; streaks must reset on any new candidate or failure.
- Unknown cleanup blocks service creation; duplicate events are noops by id; identical retries need a classified transient plus a bound.
