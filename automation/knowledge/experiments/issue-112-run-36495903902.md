- The pre-existing budget test (`test_job_poll_loop_matches_lifecycle_budget_and_covers_runner_timeout`) enshrined the literal-duplication pattern by asserting the numeric bound and guard, so it had to move to the honoring discipline with this fix.

## Interpretation

The execution failure itself is the designed response to the same systematic capacity mismatch characterized in issue #113, not a second control-plane malfunction: a ~600 MB agent workload cannot make progress on a 512 MB anytime-restart worker, and failing fast at ~11 minutes with an actionable diagnostic dominates burning the 45-minute budget for zero forward progress. The reusable defect repaired here is the poll-envelope divergence found while verifying that path: today the lifecycle constants are 140/20 in both places so behavior is identical, but any future change to `JOB_POLL_MAX_ATTEMPTS` or `JOB_POLL_INTERVAL_SECONDS` would silently diverge the loop from the reported budget (`poll $i/$POLL_MAX_ATTEMPTS`, `POLLS_REMAINING`), exactly the resolved-but-ignored class the issue #113 repair eliminated for the storm threshold. Extending that rule to the loop envelope -- rather than re-fixing the storm gate, which already handles this run correctly -- keeps the change scoped to the verified failure path.

## Reusable knowledge

- A shell-resolved lifecycle value and its use must never silently diverge: the poll-loop bound, terminal-iteration checks, and poll sleeps honor the resolved `POLL_MAX_ATTEMPTS` / `POLL_INTERVAL_SECONDS` (validated numeric, lifecycle defaults on corrupt values), extending the issue #113 threshold-honoring rule to the whole poll envelope.
- A missing numeric fallback on any resolved poll constant is the same defect class: every shell resolution in the poll stanza now fails open to its lifecycle default.
- Run 36493364897 is a second independent live validation of the replacements branch: pinned usage at exactly the limit (ratio 1.0) plus repeated instance transitions abandons with a within-group surge of only 162 and global event deltas of 0. Quiet counters do not exonerate a pinned replacement storm.
- Budget-envelope tests must assert honoring (variable use plus fallback defaults), not literal duplication, or they enshrine the divergence they were written to prevent.
