The harness classifier returns `marginal` (no 32 MiB headroom, nonzero `max` events, no OOM/failed exit). There is no boundary luck to expose: both trials agree, and the t2 trial throttled hard (126k `max` events) yet survived.
- Delta versus the historical ordinary baseline (#52 host peak 614,632 kB = 629,383,168 B = 600.2 MiB): t1 peaks at 537,804,800 B (saving 91,578,368 B, ~87.3 MiB, ~-14.5%) and t2 at 547,512,320 B (saving 81,870,848 B, ~78.1 MiB, ~-13.0%) while completing the workload the ordinary binary completes at ~600-615 MB. The saving is real but buys no headroom: the workload still throttles at the ceiling.
- The t2 `max 126848` level (vs `max ~2000` on the #126 marginal trials) shows PR #15's mini-runtime fold-out does not move the steady-state agent footprint below the throttle edge; on a noisier host either trial could plausibly have become an OOM kill. A Render Free conclusion needs a separate Render-track issue; this Docker track alone cannot certify reliability.

## Reusable knowledge

- PR #15 (`coding-no-mini`) is a 3-file mini-runtime fold-out (`script/build.ts --coding` define, `run.ts` guard, `coding-bundle.test.ts`): build it with `OPENCODE_VERSION=1.18.33 bun run --cwd packages/opencode script/build.ts --coding --single`; `--single` keeps the single-platform matrix without changing the linux-x64 binary.
- The `Script.version` contract reads `OPENCODE_VERSION` from the env (anything not starting with `0.0.0-` also forces `channel=latest`, so no git checkout is needed at build time); an unstamped merge-ref build degrades to `0.0.0-<branch>-<timestamp>` and is rejected by the free-tier gate — always fail closed on `--version` before any memory verdict.
- A `max`-stall count in the hundred-thousands with `oom_kill 0` and a clean exit is still the throttle signature of a marginal fit (t2: 126,848 events, +10.6 MiB over nominal, exit 0): record the `max` count, not just the peak, when classifying boundary trials.
- Confine agent trials to a container-mounted workdir with the harness `docker_trial_command` shape (`-w /work`, binary mounted read-only): both constrained trials stayed on-task while keeping full cgroup telemetry.
